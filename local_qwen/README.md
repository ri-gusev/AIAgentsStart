# Локальная Qwen в консоли

`main.cpp` создаёт `local_qwen::Agent` и вызывает `run()`.
Сущность агента объявлена в `agent.h`; консольный цикл, HTTP-запросы
и история диалога реализованы в `agent.cpp`.

Отдельный клиент на C++17/libcurl для Ollama. Использует существующий
`../json_value.h` для JSON. Требуются g++ и libcurl (в этом проекте — MSYS2 UCRT64).

Модель: `qwen3:8b`. Адрес: `http://127.0.0.1:11434/api/chat`.
Ollama должен быть запущен. Если сервер остановлен, запустите приложение Ollama
или выполните `ollama serve` в другой консоли.

Из корня проекта в PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\local_qwen\build.ps1
.\local_qwen\local_qwen.exe
```

Введите сообщение и нажмите Enter. `/exit` — выход. Контекст сохраняется
в оперативной памяти до завершения клиента. Ответ выводится целиком после
генерации; внутренние рассуждения отключены через `think: false`.
Первый запрос может занять больше времени из-за загрузки модели.
Таймаут запроса — 300 секунд. Ошибки HTTP выводятся в консоль;
неудачные запросы не добавляются в историю.

Для кириллицы используйте терминал с поддержкой UTF-8 (например Windows Terminal).
Клиент устанавливает UTF-8 для ввода и вывода Windows-консоли.
